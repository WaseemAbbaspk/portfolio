# Waseem Abbas — The Chronicle

Complete source for the expanded ancient-style portfolio, including machine learning, deep learning, LLMs, RAG, and agentic coding.

## Run
Extract this ZIP, then double-click index.html to open it in a browser. No build step or package installation is required.

## Edit
Open index.html in VS Code or any text editor.
- The <style> block contains all CSS. Change the :root variables to adjust the colors.
- The <body> contains the profile text, project descriptions, and page sections.
- Navigation uses links to section IDs such as #about and #disciplines.
Save and refresh your browser to see changes.

## Fonts
Cormorant Garamond and DM Sans load from Google Fonts when online. The page uses local fallback fonts when offline.

## Host elsewhere
Upload index.html to any static website host as the site's entry page. There is no backend, database, or JavaScript dependency.

This export contains the page source and this guide. Hosting account configuration and credentials are not needed to run it.

## GitHub Pages

The site is prepared for https://waseemabbaspk.github.io/portfolio/.

In the repository's **Settings > Pages**, select **Deploy from a branch**, choose **main** and **/ (root)**, and save. The root `.nojekyll` file tells GitHub Pages to serve the static files directly.

To update the site, edit `index.html`, commit your changes, and push to `main`. GitHub Pages will publish the update automatically.
