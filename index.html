Agentic coding

A developing practice of using AI agents to investigate code, plan bounded changes, implement them, and check the result. Clear requirements and human judgment give that process direction.

A disciplined workflow
Understand the repository → define the task → implement → test → review.
The engineer’s responsibility
Own the architecture, inspect the diff, validate behavior, and decide when the change is ready.
